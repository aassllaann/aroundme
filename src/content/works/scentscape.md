## An olfactory atlas

Scentscape turns perfume data into an exploratory visual system. Instead of presenting fragrance as a static catalogue, it lets visitors move between scent families, note structures, intensity, mood, and generative visual interpretations.

## What is in the system

- A D3 fragrance wheel mapping 9 families and their subfamilies.
- Search and detail views for a normalized dataset of 37,923 perfumes.
- A sillage timeline that traces top, heart, and base notes over a fragrance’s perceived duration.
- A mood-responsive canvas whose color, density, and texture change with each perfume profile.
- An optional AI route that proposes synesthetic visual concepts and p5.js generative-sketch directions.

## Position

The project treats data as material for sensory interpretation. The AI visual layer is optional: the core browsing and data experience remains useful without repeated generation.

## Status

The working prototype, data-import pipeline, and core interaction system are implemented. Final interface captures, mobile refinement, public deployment, and source-attribution polish are still in progress.
